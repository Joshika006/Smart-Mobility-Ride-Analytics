# Smart Mobility & Ride Analytics

## Project Overview

This project analyzes a real-world ride-hailing dataset using mathematical and statistical techniques.

## Technologies Used

* Python
* NumPy
* Pandas
* SciPy
* Jupyter Notebook

## Topics Covered

* Data Cleaning
* Linear Algebra
* Probability
* Descriptive Statistics
* Outlier Detection
* Correlation and Covariance
* Bootstrapping
* Central Limit Theorem
* Confidence Intervals
* Hypothesis Testing
* T-Test
* Chi-Square Test
* F-Test
* ANOVA
* A/B Testing

## Dataset

The project uses the Trip Analysis dataset containing information about trip distance, fare amount, ride category, surge multiplier, customer rating, and ride time.

## Conclusion

The analysis demonstrates how mathematical and statistical methods can be applied to ride-hailing data to understand trip patterns, pricing, demand, and service-related factors.
